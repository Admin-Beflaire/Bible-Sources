# Canonical Scripture Study — 0.1.11

Free, read-only Bible study in ChatGPT, maintained by Mark Gatzen. This public
package contains eight study skills, methodology references, the optional local
Python retrieval runtime, and one remote MCP connection.

The remote endpoint is `https://mcp.canonical-theology.com/mcp`, using no
authentication and no extra user sign-in. It accepts OpenAI connector network
traffic; it is not intended for unrestricted direct Internet or local-client
access. ChatGPT performs translation and interpretation using retrieved evidence.

Start with `Study Genesis 1`, `Full word study ruach`, or a focused study question.
English is the default; another language can be requested. Standard, Detailed
and Full depths and retained `Next` continuation are supported. The evidence
and methods are inspectable in [Bible-Sources](https://github.com/Admin-Beflaire/Bible-Sources).

The public listing targets the 27 European Union member countries. It is free,
with no purchases or paid plugin features. Directory targeting does not impose
a country firewall on the endpoint. Source coverage is selective, generated
interpretations can be wrong, and edition/source rights remain distinct.
