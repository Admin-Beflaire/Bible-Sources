Canonical Scripture Study is maintained by **Mark Gatzen**. The plugin is free; no support subscription is required.

## Get help

Use the [Bible-Sources issue tracker](https://github.com/Admin-Beflaire/Bible-Sources/issues) to ask for help, report a problem or suggest an improvement. A GitHub account is needed to create an issue; it is not needed to use the plugin in ChatGPT.

For a technical issue, include the plugin version returned by `study_health`, the Bible reference, what you expected and what happened. A short example with personal information removed is usually enough. For a source concern, identify the edition and reference, and distinguish an apparent source error from a disputed interpretation.

## Public support and privacy

GitHub issues are public. Do not post passwords, tokens, private conversation transcripts, names or other sensitive personal information. For a privacy question, describe the concern without including personal data. If the question requires exchanging private information, first ask the maintainer to agree a suitable private contact method; no private support mailbox is currently published for this plugin.

Support messages and issue attachments are handled by GitHub under its own terms and privacy policy. A public response-time commitment is not offered.

## Connection problems

Use `https://mcp.canonical-theology.com/mcp` with **No authentication**. The study tools are available only through OpenAI's connector infrastructure; opening `/mcp` directly in a browser normally returns Forbidden. A temporary rate-limit response should be retried after its indicated delay. If a problem persists, report the time and error without exposing credentials.

ChatGPT account, billing and conversation-history questions should be handled through OpenAI's own support and account controls.
